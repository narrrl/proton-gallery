# Material icon subset

Twelve outlined icon vectors are vendored from the Android Open Source Project, `androidx.compose.material:material-icons-extended:1.7.8`. Copyright headers and Apache 2.0 terms are preserved. The only source modification is package relocation to `io.narl.protongallery.icons`. Other common icons remain in the small `material-icons-core` dependency.

Official source: https://dl.google.com/dl/android/maven2/androidx/compose/material/material-icons-extended/1.7.8/material-icons-extended-1.7.8-sources.jar

Source archive SHA-256: `77b7e782a519a3e074fc91e09d59334ac1b815edd87d2e89c0c9ca7c95678e93`.

This subset avoids dexing the complete icon collection. The license is bundled under `app/src/main/assets/licenses/aosp-material-icons.txt`.
